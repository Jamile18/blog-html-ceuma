# Blog de Tecnologia

Projeto desenvolvido em HTML como atividade acadêmica do curso de Engenharia da Computação.

## Sobre o projeto

O projeto consiste na construção de um blog utilizando HTML semântico e um formulário de inscrição com validação dos campos.

## Estrutura

O projeto utiliza:

* `header`
* `nav`
* `main`
* `article`
* `aside`
* `footer`
* Formulário HTML
* `fieldset` e `legend`
* Campos obrigatórios
* Validação de nome, e-mail e idade
* `select`
* Checkbox de aceite dos termos
* Envio de dados utilizando o método `GET`

## Validações

O formulário possui as seguintes regras:

* Nome: mínimo de 3 caracteres.
* E-mail: formato de e-mail válido.
* Idade: entre 18 e 120 anos.
* Assunto: seleção obrigatória.
* Termos: aceite obrigatório.
